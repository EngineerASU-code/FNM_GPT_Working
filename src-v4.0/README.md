# Configurator 3.16.1

Изменения:
- индикация проверки сохранённых подключений БД при запуске;
- таблицы в режиме «БД проекта» выбираются кликом по всей карточке;
- реализовано «Опции → Проверить свободные поля» с выбором БД и класса;
- проверка свободных Record группирует результаты по PLC и ищет пропуски между минимальным и максимальным Record;
- добавлена кнопка обновления подключений/структуры в панели БД.


Дополнительно в 3.13:
- результаты проверки свободных битовых адресов генерируются свернутыми;
- для AI и AO используется столбец `Address`, а каждый адрес считается двухбайтовым словом;
- для AI/AO проверка больше не ищет `Address_Input`/`Address_Output`;
- проверка адресов AI/AO показывает занятость двух байтов внутри раскрываемой группы.

- В режиме 3 полностью удалён фильтр Area: остаются только PLC и Классы.
- В проверках классы в ComboBox отображаются коротким последним сегментом имени.
- Delete поддерживает удаление нескольких выбранных объектов в режиме 3.
- Системные БД не показываются в списке подключения.
